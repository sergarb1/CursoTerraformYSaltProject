Repositorio del curso *Terraform & Salt Project*, diseñado para aprender infraestructura como código y automatización de configuración desde un enfoque práctico y progresivo.  
Cada unidad incluye contenidos teóricos, casos prácticos guiados, ejemplos reproducibles y materiales complementarios orientados al entorno profesional y educativo de Formación Profesional en Informática.

Además, el repositorio incorpora **podcast de repaso de cada unidad**, disponibles en la carpeta `PodcastRepaso`, pensados para reforzar contenidos, facilitar la memorización y ofrecer un formato accesible para estudio en movilidad.

---

## 📚 Contenidos del curso

| # | Unidad | Estado |
|---|--------|--------|
| 01 | **Introducción y fundamentos de Terraform** — Conceptos base de IaC, arquitectura de Terraform, proveedores, recursos y primeros despliegues controlados | ✅ |
| 02 | **Terraform con Docker y Vagrant** — Creación y provisión de entornos locales, despliegues declarativos y automatización de laboratorios | ✅ |
| 03 | **Variables, outputs y estado en Terraform** — Gestión segura del estado, reutilización, modularidad básica y buenas prácticas | ✅ |
| 04 | **Bloques avanzados, bucles y dependencias en Terraform** — For-each, count, dinámicos, relaciones entre recursos y patrones avanzados en infraestructura | ✅ |
| 05 | **Integración de Terraform y Salt Project** — Automatización combinada, configuración remota, orquestación y flujos híbridos | ✅ |
| 06 | **Monitorización con Prometheus y Grafana** — Métricas, dashboards, alertas y supervisión de infraestructuras declarativas | ✅ |
| 07 | **Terraform y LocalStack para simular Amazon Web Services** — Pruebas locales de arquitecturas cloud, despliegues sin coste y validación previa a producción | ✅ |

---

## 🎯 Objetivos del curso

- Comprender y aplicar principios reales de **Infraestructura como Código**
- Automatizar despliegues y configuración de sistemas
- Simular entornos cloud sin depender de proveedores externos
- Desarrollar competencias alineadas con perfiles DevOps y Cloud Engineer
- Servir como recurso docente para ciclos de **FP Informática**
- Facilitar repaso auditivo mediante **podcast temáticos por unidad**
